Kajian reka bentuk. Bahan rujukan sahaja — bukan sebahagian daripada aplikasi.
Folder ini tidak menjejaskan sistem live. Fail HTML statik berasingan. Tiada perubahan pada index.html, office.html, sw.js, atau apa-apa logik. CSP sistem live tidak terjejas. demo/ tidak disenaraikan dalam sw.js ASSETS.
Gerakkan kursor perlahan-lahan merentas halaman ini. Setiap kad, tab dan carta bertindak balas. Semua ditulis dalam CSS + JS biasa — tiada React, tiada framer-motion. Guna togol di bawah untuk hidup/mati setiap kesan.

Cara ia berfungsi (ringkas). Satu pendengar pointermove pada dokumen, ditapis melalui requestAnimationFrame supaya tidak lebih daripada satu kemas kini setiap bingkai. JS hanya tulis 4 nombor ke CSS (--mx, --my, --rx, --ry); CSS yang lukis semuanya. Sebab itu ia lancar walaupun ada 16 kad.
Prestasi. getBoundingClientRect() dibaca sekali semasa kursor masuk kad, bukan setiap bingkai — membaca layout setiap bingkai ialah punca utama UI tersekat-sekat.
Aksesibiliti. Menghormati prefers-reduced-motion. Pada peranti sentuh, gerakan ikut-mouse dimatikan automatik (tiada kursor, jadi tiada makna).
