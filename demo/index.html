Demo Reka Bentuk — Sistem Pengurusan Penugasan CBT PPSKK

Kajian reka bentuk UI. Bahan rujukan sahaja — bukan sebahagian daripada aplikasi.
Folder ini tidak menjejaskan sistem live. Fail HTML statik berasingan. Tiada perubahan pada index.html, office.html, sw.js, atau apa-apa logik. CSP sistem live tidak terjejas. demo/ tidak disenaraikan dalam sw.js ASSETS, jadi PWA tidak cache ini.

Cadangan utama

Susunan 6 Kotak Sidebar Paling terkini Komandan (gambar 2:3 penuh) · Ketua Pusat Pengajian (morph, bukan scroll) · Menarik Hari Ini · Menarik Akan Datang · Jam · Kalendar. Togol kedudukan kiri/kanan. Banner + Frame Kepimpinan Realistik Pilihan pengguna Banner jadi kepingan pejal (cahaya atas, bayang bawah, kilau berus). Frame kepimpinan jadi bingkai loyang berbevel dengan gambar terbenam dan kilau kaca. Depth — gaya sama, lebih 3D Palet dan susun atur kekal. Tambah bayang berlapis (kontak + ambien + jauh), highlight atas, pengikat bawah, permukaan bergradien, gerak balas hover/tekan. Kad KPI — hover angkat + penunjuk arah Baharu Banding kad KPI semasa (statik) dengan kad baharu yang naik 5px bila hover, dengan pil peratus naik/turun dan jalur mikro. Idea diambil daripada kod React TikTok (framer-motion), ditulis semula dalam CSS biasa — tiada pustaka luar, tiada perubahan CSP. Ada togol hidup/mati.

Kajian arah lain (tidak dipilih)

Skeuomorphism — header, tab, jadual Kajian Bahan kulit navy, keluli berus, loyang PDRM. Tab tertekan ke dalam, input terbenam. Skeuomorphism — penuh Kajian Semua komponen dalam gaya skeuomorphism. Togol banding dengan kaca asal. Claymorphism Kajian Bentuk gebu seperti tanah liat. Sudut sangat bulat, tiga lapisan bayang, permukaan menggelembung. Banner dikekalkan.
