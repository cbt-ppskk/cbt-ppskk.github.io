Demo Kad KPI — Sistem Pengurusan Penugasan CBT PPSKK

Kajian reka bentuk. Bahan rujukan sahaja — bukan sebahagian daripada aplikasi.
Folder ini tidak menjejaskan sistem live. Fail HTML statik berasingan. Tiada perubahan pada index.html, office.html, sw.js, atau apa-apa logik. CSP sistem live tidak terjejas. demo/ tidak disenaraikan dalam sw.js ASSETS, jadi PWA tidak cache ini.
Asal idea: kod React dari TikTok (framer-motion, lucide-react, whileHover={{y:-5}}). Kod itu tidak boleh masuk sistem ini — projek React perlu build step, sistem ini HTML tunggal. Yang diambil idea visualnya sahaja, ditulis semula dalam CSS biasa.
