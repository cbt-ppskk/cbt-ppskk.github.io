# Gambar Staff CBT

Letak gambar personel di sini. Sistem cari gambar **mengikut nama fail**.

## Nama fail = No. Personel

```
R1234567.jpg
G1234567.jpg
```

Nama fail mesti **sama** dengan No. Personel dalam Google Sheet (tab
`Master Personel`, lajur `No Personel`). Contoh: kalau sheet catat `R1234567`,
fail mesti `R1234567.jpg`.

## Saiz

| Perkara | Nilai |
|---|---|
| Nisbah | 11:14 (menegak) |
| Saiz papar | 44 × 56 px |
| Saiz disyorkan | 440 × 560 px |
| Saiz fail | bawah 100 KB |

Kotak gambar kecil, jadi **potret menegak** paling sesuai — muka di tengah.
Gambar landskap akan dipotong tengah-tengah.

## Cara muat naik

1. Buka repo di GitHub → folder ini
2. **Add file → Upload files**
3. Seret gambar, pastikan nama fail betul
4. **Commit changes**

## Kalau tiada gambar

Sistem papar **inisial nama** (cth. "AA" untuk "ALI BIN ABU") — bukan ralat.
Jadi anda boleh tambah gambar sedikit-sedikit, tiada keperluan lengkap
sekaligus.

## Format

Guna **JPG**. Kalau ada PNG atau HEIC, tukar dulu — pelayar lama mungkin
tidak papar HEIC.
